## 重设计须遵守的标准（摘自根目录 readme.md + 商家确认）

### 对丝（DN15 成品）

- 总长 **40 mm**，六角段约 **8 mm**；建模余量按 **10 mm** 计。

### 三通 / 四通 / 五通主通（DN15）

- 对向两端口总长 **52 mm**，中心 → 单头 **26 mm**。
- 螺纹拧入约 **10 mm** → 算净直段时每端占 **16 mm**（`fittingHeadExtraMm`）。
- 例：两根净直段 **100 mm** + 一个三通 → 外轮廓总长 **232 mm**（`2×(100+16)`）。

### 直管下料

- 下料一律 **xxx0 mm**（整厘米）。
- 双端套丝：净直段 ≈ **下料 − 28**（DN15 每端 14 mm）。

### 拉结横管（备份末版布局，供对照）

- **前缘** @ `z_top`：与柱顶五通主通同高，中点三通 + 支口。
- **中间** @ 左框上半竖向中点（≈552 mm）：整根，无三通。
- **后缘** @ `z_top`：整根。

## 打开旧模型

在 OpenSCAD 中临时将本目录加入项目路径，或复制 `main.scad` 到别处并修正 `include` 路径指向本目录与根目录 `lib/`。
